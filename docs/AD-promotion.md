# Domain Controller Promotion

## Overview

This document describes the complete deployment process of the first Domain Controller in the SuHaTech enterprise homelab environment.

The deployment includes Active Directory Domain Services (AD DS), DNS configuration, forest creation, domain configuration, and post-installation verification.

---

## Objective

Create the first Active Directory Forest and deploy the initial Domain Controller.

---

## Server

- Server Name: DC01
- Operating System: Windows Server 2025 Standard

---

## Domain Controller Options

| Setting                     | Value               |

| Global Catalog              | Enabled             |

## NetBIOS Name

| Setting             | Value |
| ------------------- | ----- |
| NetBIOS Domain Name | CORP  |

### Notes

The default NetBIOS name was accepted because it matches the corporate naming convention.

## Database Paths

| Component | Path              |
| --------- | ----------------- |
| Database  | C:\Windows\NTDS   |
| Log Files | C:\Windows\NTDS   |
| SYSVOL    | C:\Windows\SYSVOL |

### Notes

The default paths were selected because this is a single-server homelab environment. In enterprise deployments, databases and log files are commonly stored on separate storage volumes for improved performance and resilience.

### Result

✅ All prerequisite checks passed successfully.

### Warning

A DNS Delegation warning was displayed because the lab uses an isolated internal domain (`corp.suhatech.local`) without a parent DNS zone.

This warning is expected in a standalone homelab environment and does not prevent the installation.
