# monitoring

# 1- Event Viewer

## Objective

Learn how to use Event Viewer to monitor Windows Server, identify system events, and troubleshoot common issues in an Active Directory environment.

---

# What is Event Viewer?

Event Viewer is a built-in Windows tool that records system, security, application, and service events. It helps administrators investigate problems, monitor server health, and identify security-related activities.

---

# Windows Logs

## Application

Contains events generated by installed applications and services such as SQL Server, IIS, backup software, and third-party applications.

**Examples**

- Application crash
- Backup failure
- Software errors

---

## Security

Contains security auditing events.

Common events include:

- User logon
- Failed logon attempts
- Password changes
- Account lockouts
- Group membership changes

This log is one of the most important logs for Active Directory administrators.

---

## Setup

Stores events related to Windows installation, updates, and server roles/features.

Examples:

- Windows Updates
- AD DS installation
- DNS Role installation

---

## System

Contains events generated by Windows components such as:

- Drivers
- Windows Services
- Hardware
- Network
- Operating System

This log is commonly used during troubleshooting.

---

## Forwarded Events

Stores events collected from remote computers using Windows Event Forwarding (WEF).

---

# Event Levels

Windows categorizes every event by its importance.

| Level       | Description                                              |
| ----------- | -------------------------------------------------------- |
| Information | Normal operation                                         |
| Warning     | Potential issue that may require attention               |
| Error       | A component or service failed                            |
| Critical    | Serious system failure requiring immediate investigation |

---

# Event Properties

Each event contains useful information.

- Log Name
- Source
- Event ID
- Level
- User
- Computer
- Date & Time
- Description

---

# Source vs Event ID

## Source

Identifies which Windows component generated the event.

Example:

```
Service Control Manager
```

---

## Event ID

A unique identifier representing a specific event type.

Example:

```
7036
```

Searching the Event ID often helps identify the cause of a problem.

---

# Filtering Events

Event Viewer allows administrators to filter logs based on:

- Event Level
- Event ID
- Date and Time
- Log Source

Filtering reduces thousands of events to only the relevant ones during troubleshooting.

---

# Practical Tasks Completed

- Opened Event Viewer
- Explored Windows Logs
- Reviewed Event Levels
- Opened and inspected event properties
- Compared Source and Event ID
- Filtered events by Level
- Filtered events by Event ID
- Cleared active filters

# Summary

Event Viewer is one of the primary troubleshooting tools in Windows Server. It enables administrators to investigate system, application, and security events efficiently by using event logs, filtering, and Event IDs.
