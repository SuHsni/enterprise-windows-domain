# Security Group Design

## Overview

This document describes the initial Security Groups created for the SuHaTech Active Directory environment.

---

## Objectives

- Simplify permission management
- Follow enterprise best practices
- Prepare for future file server permissions
- Prepare for Group Policy assignments
